# RealEstateIQ

**Live app:** https://main.d16kmuoaysnnkl.amplifyapp.com

RealEstateIQ is designed for first-time real estate investors who struggle to determine whether a property is actually a worthwhile investment. A user enters a property’s basic information, such as purchase price, expected rent, financing, and renovation costs, and RealEstateIQ analyzes the deal to produce a clear investment assessment. The AI evaluates the numbers and assumptions, identifies the biggest risks, and explains what would need to change for the property to become a stronger deal. This allows the user to understand not only whether the property appears financially viable, but why. RealEstateIQ is for informational purposes only and does not provide financial or investment advice.
