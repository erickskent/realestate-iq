# RealestateIQ
RealEstateIQ is an AI-powered real estate decision-support platform that helps users understand the financial potential, risks, and opportunities of a property by combining listing information, financing, rental estimates, and renovation assumptions into an interactive deal analysis. Rather than simply calculating investment metrics, RealEstateIQ will help users explore different scenarios, stress-test a deal, and understand what would need to change for a property to become financially viable.
